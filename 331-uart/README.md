# Расчёт допуска скорости UART

Скорость UART1 смещается относительно UART0 (115 200 бит/с).

Допуск приёма: старт-бит и 8 битов данных занимают 9 битовых интервалов.
Приёмник выбирает середину каждого бита. При расхождении скоростей на p%
к полному байту набегает 9 · p/100 битовых интервалов. Ошибка возникает,
когда смещение достигает половины интервала: 0,5 / 9 ≈ 5,5 %.

Экспериментально: при -2 % строка из 32 символов проходит без ошибок,
при -10 % появляются ошибки кадра (FE).

Граница допуска: около 5 %.
