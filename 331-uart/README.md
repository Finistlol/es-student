# Задание п3.3.1 — Драйверы линии

## Расчёт постоянных времени

### Двухтактный режим (edge pp)

Цепь: GP22 → R = 1 кОм → узел, C = 4,7 мкФ → земля.
Заряд и разряд идут через один резистор 1 кОм.

τ = R · C = 1000 Ом · 4,7·10⁻⁶ Ф = 4,7 мс

Время роста до 2,0 В (от 0 В): t = τ · ln(3,3 / (3,3 − 2,0)) = 4,7 · ln(2,54) ≈ 4,4 мс
Время спада до 1,3 В (от 3,3 В): t = τ · ln(3,3 / 1,3) = 4,7 · 0,934 ≈ 4,4 мс

Оба фронта должны быть близки: отношение около 1.

### Открытый сток (edge od)

Заряд: через внутреннюю подтяжку 50–80 кОм.
τ = R_pullup · C = 50000 · 4,7·10⁻⁶ = 235 мс (минимум)
τ = R_pullup · C = 80000 · 4,7·10⁻⁶ = 376 мс (максимум)

Время роста до 2,0 В: от 220 до 350 мс — сотни миллисекунд.

Разряд: через вывод как ключ на землю, сопротивление ключа мало.
Время спада до 1,3 В: единицы миллисекунд, как в двухтактном режиме.
