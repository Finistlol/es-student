# es-student

Репозиторий курса «Встраиваемые системы» (ant-lab).

## Проекты

| Папка | Задание | Описание |
| --- | --- | --- |
| `112-blink` | 1.1.2 Первый проект | Мигание светодиодом на выводе 25 |
| `121-blink-reg` | 1.2.1 Мигание светодиодом через регистр | То же через регистры SIO |
| `122-led-button` | 1.2.2 Светодиод и кнопка | Переключение по нажатию |
| `123-led-button-debounce` | 1.2.3 Программное избавление от дребезга | Фильтрация дребезга |
| `131-hello-usb` | 1.3.1 Hello World USB COM | Вывод в USB COM-порт |
| `133-led-button-usb` | 1.3.3 Вывод состояния светодиода | Обмен символами |
| `134-led-module` | 1.3.5 Модуль светодиода | Разделение на модули |
| `211-command-usb` | 2.1.1–2.1.6 | Прибор, отвечающий на команды |
